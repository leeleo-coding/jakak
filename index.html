coeval_cal

A personal YouTube publishing tool

Effective August 12, 2026 Contact joonsuk.lee@gmail.com

Purpose

coeval_cal is a personal automation tool, written and operated by a single individual developer, that publishes pre-produced video content to that same developer's own YouTube channel using the YouTube Data API. It is not distributed to, or used by, any other person.

Privacy policy

The sections below describe what Google account data this app accesses and how it is used.

Who can use this app

This app has exactly one user: its developer. It is not a public product, is not distributed through any app store or marketplace, and does not accept sign-ins from any Google Account other than the developer's own. There is no user registration, no public-facing interface, and no mechanism for a third party to authorize this app against their own Google Account.

What data we access

To publish videos on the developer's behalf, the app requests the following Google OAuth scopes, all scoped to the developer's own YouTube channel:

  • https://www.googleapis.com/auth/youtube.upload Uploads video files to the developer's channel.
  • https://www.googleapis.com/auth/youtube Sets video titles, descriptions, tags, and manages playlists on the developer's channel after upload.
  • https://www.googleapis.com/auth/youtube.force-ssl Same channel-management actions as above, requested over an encrypted connection.

The app does not request access to Gmail, Drive, Contacts, or any Google data outside of the developer's own YouTube channel.

How this data is used

Video files, titles, descriptions, and playlist assignments are used solely to publish content the developer has already created, directly to the developer's own channel. The app does not analyze, profile, resell, or otherwise use this data for any purpose beyond performing the specific publishing action the developer initiates.

No data collected or accessed through these scopes is shared with, sold to, or disclosed to any third party, advertiser, or other Google API client.

Where data is stored

The app runs entirely on hardware owned and controlled by the developer. There is no server component, no hosted database, and no cloud storage operated by the app. OAuth credentials (an access token and refresh token) are written to a single local configuration file on that hardware and are used only to make authenticated requests to the YouTube Data API on the developer's behalf.

Access can be revoked at any time from Google Account → Security → Third-party access. Revoking access immediately invalidates the locally stored credentials.

Children's privacy

This app is not directed at children and is not designed for or marketed to anyone other than its single adult developer-user.

Changes to this policy

If the scopes or purpose of this app change, this page will be updated and the effective date above will change accordingly.
